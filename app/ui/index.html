            飞牛官方套件
            连接状态：启动时自动侦测
          

        

        

          只接飞牛应用中心里的官方「迅雷」：启动时会自己侦测网关端口、复用当前飞牛登录态，
          不需要选模式或填端口；连不上就点上方「重连并诊断」——主用后端是迅雷时，
          它会先测一遍，不通就自动重新侦测网关并重连。

令牌来源：—

        
投递报 invalid token 时，先点上方重连并诊断：它先测一次，
          不通就自动重新侦测网关并重连，并直接告诉你是登录 Cookie 还是 pan_auth 的问题，
          别再盲目重登迅雷。从飞牛桌面点开本面板会把浏览器的登录 Cookie 写进配置（网关模式下才写），
          Telegram 那条路径也就能用上新 Cookie 了。

        
报 parent folder not found 是「下载目录 id」对不上（换设备、重装迅雷、
          目录被删，或把路径填进了 id）：留空就是迅雷默认下载目录；要指定目录，在迅雷面板的文件列表里选中目录，
          从地址栏 parent_folder_id= 后面复制那串 id。
          开着下面的开关时，投递撞到目录类错误会改用默认目录继续，但不会改动你填的设置。
